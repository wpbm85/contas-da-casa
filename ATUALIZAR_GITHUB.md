# Atualizar para v10.4

1. GitHub > Add file > Upload files.
2. Envie todos os arquivos deste pacote para a raiz.
3. Commit sugerido: `Oculta valores por padrão v10.4`.
4. Aguarde o GitHub Pages atualizar.
5. Reabra o app.

O padrão desta versão é abrir com os valores ocultos.
O botão 🙈/👁️ no topo alterna a visualização e memoriza a escolha neste aparelho.
Não é necessário executar SQL nem alterar o Supabase.
