# Correção v7.1

A v7 publicada tinha um erro de sintaxe em `app.js`, por isso a página carregava visualmente mas nenhum botão respondia.

Para corrigir o GitHub:
1. Abra o repositório `contas-da-casa`.
2. Clique em **Add file > Upload files**.
3. Arraste TODOS os arquivos desta pasta/ZIP.
4. O GitHub mostrará que os arquivos existentes serão substituídos/atualizados.
5. Commit message sugerida: `Corrige JavaScript da v7`.
6. Clique em **Commit changes**.
7. Aguarde o GitHub Pages publicar novamente.
8. Abra o site e faça **Ctrl+F5** no PC para forçar a atualização.
9. No celular, se a versão antiga tiver ficado em cache, feche e reabra; se necessário, limpe os dados do site ou reinstale depois.

Não precisa alterar Settings > Pages.
